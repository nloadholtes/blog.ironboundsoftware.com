# A weeks worth of headaches in an hour

I of course love how using an LLM can let me get so much done in such a short period of time. But there is one thing I can't get used to: how quickly I run into problems.

In the past, I typically would run into 1 problem at a time because I could only move so fast. Now, because I either have parallel lines of working happening, or I'm just plain moving faster, I seem to run into more problems faster.

Don't get me wrong, these are all solvable things but it is just mentally taxing to suddenly have a processing issue, an oauth issue, and a "oops we shouldn't have done it that way issue" all pop up with 5 minutes of each other.

Again, time to shift how the profession of Software Development does its job I suppose.
