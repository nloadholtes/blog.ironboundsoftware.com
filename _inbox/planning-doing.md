# Planning, doing
Tags: thinking

Part of this "write every day" challenge is help me learn to plan things out a little bit better.

While I like doing, planning has always been a challenge. I'm very much in the camp of "Good enough, let's go" when I probably should spend like 5 more minues and refine the plan a little bit more.

I thought AI would be able to help me with this, but I've found the opposite to be true: Claude has produced plans at work that seem overly complicated, and the accuracy of the plan really falls off in the last 3rd of the tasks.

So for this project I:
- Opened up google keep and wrote down 10 topics I think I could write about
- Put a daily task in todoist to remind me to write
- Asked Claude to make this as streamlined as possible

A fairly simple plan. If I can't accomplish this... yikes I probably have bigger problems.

So in the coming days expect to see more about: Space exploration, software and AI thoughts, taking action, and other aspirational topics.
